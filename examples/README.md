# Examples

- **[demo-app/app.js](demo-app/app.js):** a tiny program with a deliberate bug (`average([])` returns `NaN`, and the program then stops with an error and exit code 1). Open its folder in VS Code and follow [tutorial 1](../docs/tutorials/01-record-your-first-bug.md) to record it. It needs [Node.js](https://nodejs.org) to run: install it, then run `node app.js` in the VS Code terminal.
- **[sample-report.md](sample-report.md):** the kind of report Dashcam saves. The Environment values and times are examples.
